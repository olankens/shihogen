# AGENTS

## COMMIT MESSAGES

* Always add cspell words in lowercase, sorted and one per line.
* Always classify the README.md or .assets/ changes as docs type.
* Always follow the commitlint configuration from the package.json.
* Always keep every commit subject short, concise and easy to scan.
* Always omit the scope when the project repo is not a monorepo.
* Always start every commit subject with a clear indicative verb.
* Always use the and word before the final item in all enumeration.
* Always use the affected workspace or package name as commit scope.
* Never add co-authored-by trailers from any agentic tool or agent.
* Never classify shell script changes as the docs commitlint type.
* Never employ the --no-verify flag to bypass local commit hooks.
